# F0 ×2 大裁剪微调，LR96／HR192

两组各10K更新，共20K。l1_lr5使用RGB L1，mse_lr5使用RGB MSE，两组固定学习率5e-6。均从原982K权重及相同随机状态启动，新建Adam，保持原betas/eps、有效batch64、micro16、累积4次、clip0.1、FP32。裁剪由原LR64/HR128扩大为LR96/HR192。

这是新训练条件的假设检验，尚无PSNR增益结论。初始权重没有使用上一轮微调权重。原训练源manifest中的hr_patch=128用于确认来源，微调实际protocol中hr_patch=192，并额外记录lr_patch=96。

预检核对全部DF2K3450对数据哈希、尺寸和训练评测分离。任何训练图不能裁出LR96时均停止并报告文件，避免静默改变样本集合。服务器真实982K检查包括奇数尺寸、x8变换、两组micro16/accum4梯度与参数更新。首组开始前复现原982K全部六集合plain/x8指标。

输出使用runs/FT-X2-982K-PC96-<arm>-10K-v1，微调步数0到10000，每1K保存完整恢复断点和逐图评测。两组均新建Adam，是延续上一轮微调对照的设置。学习率在10K阶段保持固定。

## ×8目标

目标为Set5、Set14、B100、Urban100、Manga109的x8 PSNR。comparison.json按五集合最后5次评测的x8平均PSNR增量记录target_mean_delta，并报告固定10K同权重结果、各集合差值及五集合是否全部上涨。DIV2K继续记录。最后5次均值是指标均值，不是权重平均。

这是使用常用测试集探索微调的实验，应披露选型方式。所有训练样本来自DF2K，测试图只评测。方法不保证五集合同时改善。与上一轮patch64结果比较时，应同时报告训练更新预算和像素处理量增加，大裁剪每个样本像素数为原来的2.25倍。

## 自动归还

worker.sh接受三个参数，分别为独立代码目录、原1M运行目录、日志group。AUTO_RELEASE=1时，两组都完成且finalize.py逐文件fsync/读取哈希、断点和指标检查通过后，调用featurize instance release。任一步失败则保留实例并记录FAILED。未使用曾出现NFS错误的sync -f整文件系统操作。

finalize.py核验每组所有1K断点、逐图指标、协议和日志均位于持久化work。权重与结果不自动上传GitHub。

## 本地与服务器验证范围

QA-local.json记录本地检查结果。真实982K权重及全部数据的检查仍在服务器执行，启动前需要保持原数据路径可读。
