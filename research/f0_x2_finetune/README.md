# F0 ×2，982K起点的损失微调对照

此分支增加独立微调入口，骨架源码为0748bd60c1eaddda4e0db7f01ba768a0f2a22be3。四组均从已验收的epoch00982_u982000.pt严格加载模型，权重SHA256在run.py中固定。每组额外10K，共40K更新。

| 组 | 损失 | 固定学习率 |
|---|---|---:|
| l1_lr125 | RGB L1 | 1.25e-5 |
| l1_lr5 | RGB L1 | 5e-6 |
| mse_lr5 | RGB MSE | 5e-6 |
| l1_to_mse_lr5 | 前5000步RGB L1，后5000步RGB MSE | 5e-6 |

四组均新建Adam，betas=(0.9,0.999)、eps=1e-8，避免把原L1训练历史只带入部分候选。这个决定与此前初版“保留Adam状态”的设想不同，实际代码和结果应按本表记录。每组恢复相同982K随机状态，训练使用DF2K3450对，LR64/HR128、micro16、累积4次、FP32、全局梯度裁剪0.1。MSE梯度尺度与L1不同，裁剪仍统一以原始RGB L1监测严重预测异常。MSE原值没有任意缩放。

每1K通过原评测入口评测六集合plain+x8，Y通道裁边2、量化uint8。起点普通及x8指标在首组训练前全量复现，差异超过2e-6时停止。数据哈希与有序配对预检后，实际micro16/accum4工程检查通过才开始四组训练。

## 目标与报告规则

用户目标为Set5、Set14、B100、Urban100、Manga109。主报告为固定10K同权重结果和最后5次评测均值。comparison.json记录五集合plain平均PSNR差值、逐集合差值、plain与x8五集合是否全部改善。DIV2K继续报告。最后5次是五个checkpoint各自的指标均值，不是权重平均或联合推理。

这是明确面向五个常用测试集的探索性对照。若依据这些测试结果选择方法，论文应披露测试集选型，并使用新的独立评测证据检验泛化，不能称这些集合仍是完全未参与选型的测试集。训练样本只来自DF2K。

候选不会自动根据测试分数改变学习率、数据或训练预算。不能预先保证所有集合提高。结果中不拼接各测试集不同checkpoint的最高值。

## 入口与恢复

worker.sh负责全量数据审计、工程检查和四组串行训练，默认保留实例。run.py的阶段计数从0到10000，所有输出位于runs/FT-X2-982K-<arm>-10K-v1。已有运行目录拒绝覆盖。

单组中断后，在相同源码及group下使用run.py的--resume恢复。每组初始验证后就保存step0完整断点，每1K保存模型、Adam及所有随机状态。resume会截断最新完整断点之后的日志。末阶段没有scheduler，固定学习率直接写入新协议。原训练的1M计数与微调计数分别记录。

verify.py检查L1/MSE导数、5K切换边界、CPU/CUDA的2+2与4步完整状态等价。--source-run会额外检查实际982K模型、奇数与窗口不可整除尺寸、四组micro16/accum4真实梯度和参数更新。最终数据收益由服务器正式运行给出。
