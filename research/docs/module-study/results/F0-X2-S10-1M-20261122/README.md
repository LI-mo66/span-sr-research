## 模型及证据范围

F0在SG6基础上包含第2、4块后的独立UCAN上下文分支、第3块后的部分通道窗口交互、第5块后的LKSA，以及bound8特征约束。六个SPAB采用52通道。×2部署参数为552003，来自已完成的服务器真实样本验收。

本次为seed10单次训练轨迹。×2 B0只完成了50K对照，不能将F0的1M结果表述为相同训练预算下相对B0的收益。×2和×3分别训练。主结果按普通DIV2K_valid选权重，测试集最高分没有用于逐集合挑选权重。
