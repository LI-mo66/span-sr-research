# 固定F0从零百万步正式训练

DF2K=DIV2K800+Flickr2K2650，共3450对；六集合428张保持独立。模型与F0固定结构一致，不复用旧50K权重。seed10、FP32、RGB L1、Adam2e-4、有效batch64=micro16×4。总预算1M，200/400/600/800K学习率减半；每1K更新记录一个研究epoch，非数据完整遍历。每1K保存完整断点与六集合逐图普通/×8指标。

×8使用8种D4变换，逐次推理、逆变换、浮点平均后统一裁剪和uint8量化。原始方向预测同时作为普通指标；不重复一次前向。8次推理串行，不把batch扩大8倍。输出同时记录plain与x8。以DIV2K_valid_x8最佳选一个权重报告六集合；另保存普通DIV2K最佳的best_plain.pt；best_validation.pt为x8最佳。

--until-update仅决定阶段停止点，不进入训练协议指纹。允许阶段100K/250K/500K/750K/1M，恢复使用完整latest.pt，不重置优化器/调度/随机流。每阶段完成后保留全部周期权重并做完整SHA256归档。用户可扩容；仍检查空间防止写盘失败。

launch_stage.sh check 仅进行数据/环境/源码审计、nativeCPU/CUDA测试、新旧训练一致性、精确续训、旧48K普通指标复现、真实micro16×4和×8最大图检查，不启动正式长训、不释放实例。随后launch_stage.sh 100000从零开始第一阶段。后续阶段必须使用相同源码和配置，阶段结束AUTO_RELEASE=1才释放，失败保留。

异常策略仅停止，不改变loss/梯度/LR：非有限预测、loss、梯度、更新后参数停止；loss启动前1000更新阈值100，之后阈值max(1,20×最近1000次loss中位数)，按原始microbatch L1判定。阈值是预先声明的保守运维启发式，不是最优阈值或稳定性保证。停止保留最后完整评测checkpoint与异常记录，不自动恢复或修改策略。已有工程测试不能保证百万步稳定或涨分。

trainer.py是原shared trainer的独立副本，限定改动为双模式评测、阶段cap、独立最佳记录和abort-only诊断；不修改原shared trainer。测试需证明普通训练loss/模型/Adam/调度/随机状态与原F0精确一致。参考48K权重只用于单独测试进程，不进入正式训练进程。
