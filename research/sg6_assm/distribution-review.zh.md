# 特征分布、归一化与优化复审

2026-10-21。复审对象：b7f821ffeafa3cb15e2cb45930a28deb2dafc4e3 的中段原型。

**结论：中段版本暂不进入 50K。归一化数量不是目前主要证据指向的问题；
路由/状态参数的有效优化太弱，需要先处理接入位置与梯度衰减。**
本次不修改生产 adapter、位置、归一化、初始化或训练设置。

## 证据边界

诊断为固定 seed10 的从零模型、两张随机 RGB 输入、13x17 LR、公共 Adam
lr2e-4/betas0.9,0.999/eps1e-8、最多8次合成更新、纯参考 scan。
不是已训练 SG6 的真实图像特征，不是长期路由行为或 PSNR 证据。
数据在 `distribution-synthetic.json` 和 `normalization-placement-diagnostic.json`。

## 1. 分布与幅值

初始第三块 F RMS=0.04827；ASSM 原始输出 RMS=0.14338；乘0.01后修正
RMS=0.001434，约主路2.97%。相加后 F 的 RMS 仅增加0.070%。
这说明此诊断中没有初始幅值爆炸，不能据此断言真实图像和整个训练阶段的分布已匹配。

8步后 F RMS=0.58912，修正 RMS=0.001357，相对量降至0.230%。
输入与输出 LN 让新路幅值较稳定，但不保证它能随 SG6 主路幅值共同增长。
在受控 offset/gain 探针中，LN 让修正几乎不随公共偏置和正比例变化；
原图幅值仍沿未归一化的 F 直通。这是其稳定性作用及幅值适配限制的两面。

## 2. 两个 LayerNorm

原 SG6 无 LayerNorm；本候选新增两个，都是每像素52通道，eps1e-5：
输入 LN -> 1x1/CPE -> 排序/状态扫描 -> 输出 LN -> Linear -> scale -> F相加。
它们中间有实际变换，不是连续对同一张量重复归一化。
F直通、融合头和RGB输出没有新增LN/BN。

同起点单步反事实中：移除输入LN，路由第一层梯度 RMS 从2.94e-15降至4.97e-18，
FP32 Adam实际更新变为0；移除输出LN，梯度降至9.11e-16。
这不证明两个LN能提高PSNR，但不支持“删除一个LN就能解决优化”的判断。

## 3. 优化弱启动：非零梯度不等于有效学习

首步路由第一层权重 RMS=0.02013，梯度 RMS=2.94e-15，Adam实际更新
RMS=1.56e-11，参数相对更新仅7.75e-10；第8步仍是同一极小量级。
公共 Adam eps=1e-8，在这类极小梯度下不能自动将其完全归一化成常规步长。
状态A_logs首步相对更新2.07e-7，而外层scale相对更新约1.90%。
因此先前“22个张量均有梯度且更新”只能算连通性通过，不能作为路由已有效学习的结论。

硬排序本身无梯度，路由主要借助ST提示路径收到梯度；它还经历提示池、小残差scale和
后面三个SG6块的传播。这个组合需要检查，不能机械加卷积/激活解决。
共享一个RGB L1、无辅助loss、Adam无weight_decay，没有发现直接的目标/配置冲突；
但没有做长期梯度方向分析，不能宣布联合优化已无冲突。

## 4. 位置与归一化的同起点诊断

所有反事实使用完全相同的SG6和adapter权重、输入/目标及一次Adam更新：

|位置/设置|路由第一层梯度RMS|路由相对更新|修正/输入RMS|
|---|---:|---:|---:|
|mid3, alpha=.01|2.94e-15|7.75e-10|2.97%|
|mid3, 无输入LN|4.97e-18|0|2.47%|
|mid3, 无输出LN|9.11e-16|2.31e-10|0.798%|
|mid3, alpha=.1|2.94e-14|2.89e-8|29.7%|
|融合头后, alpha=.01|3.00e-12|2.98e-6|0.0101%|
|融合头后, alpha=.1|3.00e-11|2.96e-5|0.101%|

融合头后的一步梯度明显更强，是位置相关传播的证据，而不是尾部位置能提高PSNR的证据。
单纯把中段alpha扩大10倍，既不足以解决路由更新极弱，又让局部修正达到输入约30%。
故不直接调大alpha，也不改公共Adam eps、额外添加分组LR或堆激活。

## 后续闸门

1. 当前中段原型标记HOLD；已有kernel-probe仍可用于同一个ASSM核心的内核检查。
2. 原生内核通过后，在真实小批图像上核验特征幅值、更新比例和路由利用情况；
   若用已训练SG6权重观察分布，必须明确仅作冻结诊断，不能用于候选训练初始化。
3. 位置/初始化改动若成为新候选，建立新版本与独立配置/ID，不把它混入当前中段记录。
4. 保持SG6公共训练协议，先解决新路有效学习，再考虑唯一一组正式50K。

原SG6及历史实验均不修改。此次未启动服务器训练、未改全局skill或环境。
