# SG6 六方案短筛

每个分支直接以固定 SG6 e731483d4ce4e325f3d64dbbc80add342b46f7f1 为父提交，只增加本实验目录。原实现、旧 UCAN 实验和产物保持不变。

三种双单元位置 1/3、4/6、2/6 与既有 2/4 比较；all6 是增加容量实验，非等参数位置消融；LKSA5 与 P24+LKSA5 是独立及组合对照。均从零 seed10、50K、原 MultiStep，每1K评测，按DIV2K_valid最高PSNR选择一个权重报告六集合。仅短筛，不承诺长训或跨seed增益。

上下文实现原样复制已训练 independent-v2 的 attention.py。按出现顺序初始化两个slot，seed+80001隔离RNG；2/4组合的两个上下文初值与旧实验一致。六处全部加入新增55068参数，超过旧两单元设计的10% SG6增量上限，明确标记为容量扩展，不在暗中沿用该上限。

LKSA为vendor锁定Apache2源码的完整同名类，C52、k35、ratio4，核心8203参数。不要依赖源码注释中的dynamic/global-context描述，实际forward是分解深度卷积、局部卷积、通道投影后相乘。外部使用 x + rms(x)*ZeroConv1x1(LKSA(x/rms(x)))，RMS为逐图全通道空间统计、detach、下限1e-6；额外投影2756参数，合计10959，无新LayerNorm。零初始化投影使初始输出恒等；内部首步零梯度合理，后续启动必须通过检查。完整源LKSA不等于原UCAN整网复现。

接口：输入输出B52HW；逐像素位置不变；奇数长宽和非方形均可；无窗口padding，无QK跨图缓存；所有上下文独立计算QK，非共享实验。scale仅为当前图计算，不保存状态。适配器在各块完整输出后、下一块前；第1块后加入时，原融合头的b1也接收该修正；第6块后加入只修正其最终输出，原first中间特征融合支路不改。位置比较包含这些骨架既有路径差异。

独立LKSA与组合LKSA固定在第5块后，使用相同核心和投影初值。组合版上下文仍位于2/4；没有同时修改优化器、LR、损失、归一化或GB旁路。检查原forward加hook oracle、LKSA源公式前后向、尺寸、非零投影、真实梯度启动、优化器保存重载、4步真实入口精确续训。资源为同设备完整fused模型FP32 TF32关闭；训练精度匹配原归档。组件单独计时不等于端到端时间分解，未报告的FLOPs不编造。

服务器队列nohup串行执行，先通过六项全部预检再开始真实训练；任一步失败停止并保留实例。每项结束单独备份权重、配置、源码、日志、逐图结果并hash校验。六项全部成功后再校验六份归档、打包汇总，GPU无其它任务时才申请释放。只有release命令记录不能代替平台关机确认。不会自动续训、改microbatch、安装升级依赖或复用失败目录。

候选众多增加选择偏差，最终赢家仍需独立seed确认。固定权重干预只能说明依赖；所有涨点来自真实独立训练结果。主对照SG6，附与旧上下文2/4的同选权重和固定50K比较，测试集不用于选择架构位置。
