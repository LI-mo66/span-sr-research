# SG6 中段部分通道窗口交互 A 与局部卷积对照 C

固定基座：`e731483d4ce4e325f3d64dbbc80add342b46f7f1`，部署参数535772。所有改动仅在本目录；不覆盖原SPAN、SG6或共同训练器。

## 来源与证据边界

- MambaIRv2 / ASSM（CVPR2025）是上一轮尾部实验的机制。其SG6短筛未达到整体PSNR提升目标，不能据此否定ESC。
- ESC（ICCV2025）：https://arxiv.org/html/2503.06671v2 ，官方实现 https://github.com/dslisleedh/ESC/tree/f22c712a57c664360f9af3a77cfc527c414067c4 。其窗口注意力保留二维相对位置偏置，后续卷积传播窗口间信息；ConvAttn是共享大核+动态卷积。
- 本项目仅参考空间窗口注意力思想，独立实现标准QKV/softmax/RPE公式，不移植ESC整网、ConvAttn、动态/共享大核、FlashBias或ASSM，不声称复现ESC论文性能。
- 本次同时改变相对上一轮的机制与位置，是候选筛选，不能归因上一轮究竟因排序还是位置失败。

## 接口与结构

SG6实际forward为block1→block2→block3→block4→block5→block6→conv2→conv_cat→重建头，并保留浅层、多阶段拼接和GB图像旁路。

本实现包装block3，只修改返回tuple的第一个主输出，其他返回值与原forward保持一致。输入输出均为N×52×H×W，RGB输入输出仍为N×3×H×W及N×3×4H×4W，FP32，同device，无降采样。

Fa=F[:,:26]、Fb=F[:,26:]；Y=concat(Fa+alpha*core(LN(Fa)),Fb)。所有52通道均保留恒等残差路径。新增一处逐像素26通道LN，恒等路径不归一化，无BN、后置ReLU、额外完整FFN或幅值恢复。最终v2的alpha逐通道可学习，初始化0.03且核心输出投影非零，首步能够更新内部参数。0.03是已通过工程检查的起点，不宣称PSNR最优。

|版本|修正核心|新增参数|部署参数|
|---|---|---:|---:|
|A|26通道、16×16窗口、2头×13维、完整二维RPE|4808|540580|
|C|26→20的1×1，20→20普通3×3，20→26的1×1，内部GELU|4784|540556|

两者使用相同LN、逐通道alpha、原生fan-in核心初始化及std0.02小输出投影、相同新增模块独立RNG种子；核心偏置置零，原SG6参数与初始化随机流严格保持。初始化修正量仍不同，报告分别记录，不将参数接近描述成计算量/初始化效应完全匹配。

history/small-init-*保留最初全部线性/卷积std0.02、alpha0.01的工程诊断与实现。它虽有非零梯度与更新，但RPE更新过弱，不能据此称有效学习。最终v2只将写回投影设为小权重，核心保持原生fan-in初始化，并将公共alpha改为0.03；CPU四步诊断最大修正相对RMS为A约1.40%、C约0.315%，RPE实际更新提高，未增加额外LN或RMS恢复。该调整只根据工程证据，不根据测试集PSNR调参。

A固定不shift、不dropout、不语义排序、不跨图统计、不状态扫描。窗口按照原二维网格划分，右/下补零，补入的key在softmax前屏蔽，输出移除补边。每窗至少一个真实像素，不产生全屏蔽softmax。RPE索引是key-query，H/W顺序、通道顺序、padding及反变换由独立逐窗FP64参考验证。单窗口交互不是全图建模；跨窗口信息依赖后续SG6卷积。

为限制注意力矩阵的瞬时显存，固定每次128个窗口分批计算，保留完整RPE和同一attention定义，不使用低秩近似。分批不减少全部训练激活的总规模，仍需实测micro16与最大整图。

## 工程验收和长期观测

verify.py检查奇数/非整除/小于窗口/长宽不等/非连续内存输入、图像隔离、未处理通道原样通过、完整SG6恒等映射与非零GB旁路、原参数及RNG保持、仅一处LN、optimizer覆盖、有限梯度、真实Adam更新、原六块空间分支启动、严格保存恢复和部署融合。

四步合成诊断记录中段特征及第4块输入分布、修正相对RMS和逐参数梯度/更新。5%是初始化附近的本地工程检查线，不是普适稳定性或PSNR标准；不要求新旧梯度始终同向。通过这些检查不等于排除所有分布/优化耦合问题。

正式训练额外在更新1、1000、10000、25000、50000读取特征、残差、alpha和实际Adam更新，写入mid-diagnostics.jsonl。监测不改loss、梯度、优化器、RNG或模型state_dict；有独立“监测前后权重一致”测试。记录到下一次forward（包括eval）时读取实际更新。当前自动worker仅从零启动。

integration.py用真实训练入口的两次合成更新测试梯度累积、缓存、评测、损坏日志恢复和严格续训；工程权重丢弃。server_smoke.py用真实图像裁剪micro16×4更新一次，再测试全部验证集中面积最大的LR图像整图推理。benchmark.py在同设备同尺寸、FP32预融合条件下warmup并轮换测量SG6/A/C；小参数增量不保证低延迟。

本地检查使用torch2.9.1+cu128/RTX4060 Laptop，不替代服务器torch2.2.2+cu121/RTX4090复验。模块只使用普通PyTorch，不需要安装Mamba、FlexAttention或升级SG6环境。服务器各闸门全部通过后才训练。
